# Eval

Read and follow the [Eval playbook](../poteto-mode/playbooks/eval.md). It defines
the comparison, run isolation, evidence, and scoring. For requests to design a
study, return the protocol and fixtures that the user requested. Run candidates
when the task and available host capabilities support execution. Existing
outputs can be evaluated without rerunning their candidates.
